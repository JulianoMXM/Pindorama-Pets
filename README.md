Projeto Pindorama Pets

Criação de um site utilizando das linguagens HTML, CSS e JavaScript para a Unect Jr.
O projeto tem como objetivo desenvolver as capacidades dos trainees acerca das principais linguagens utilizadas, desenvolvendo a busca por se desenvolver além do básico, autodidatismo e capacidade de evolução. Para esse projeto, foi proposto um projeto no figma, com alta fidelidade, o qual foi replicado seguindo o máximo possível a fidelidade de acordo com os conhecimentos aprendidos durante o projeto. O projeto conta tanto com um modelo Desktop quanto um modelo mobile, necessitando, portanto, de responsividade entre os modelos. Para realizar essa responsividade, primeiro foi feito o modelo desktop e em seguida, adaptado ao mobile, fazendo as mudanças necessárias no CSS e JavaScript para que o site respondesse de acordo com o esperado, além disso, para um melhor continuidade do projeto, o padrinho ajudou a desenvolvê-lo, tirando as dúvidas necessárias para a continuação deste.
